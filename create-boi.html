README

                    

                        
1) Load your Mixamo avatar from Cargar FBX local or drag/drop GLB/FBX into viewport.

                        
2) Load extra animation files with Cargar animación. If skeletons differ, use Retarget Selected Clip.

                        
3) Build blends in Layer Stack using per-layer masks and weights.

                        
4) Morph targets auto-populate in Morphs; save or restore a morph state.

                        
5) Export full setup as editor-compatible JSON or bake stack to GLB.

                        
Known limits: retargeting is Mixamo-oriented and may need manual bone offsets for non-standard rigs; baked GLB samples at 30 FPS by default.
